# Grill-me Skill

## Purpose

递进式需求确认对话技能。Agent 通过递进式提问帮助用户澄清需求、
界定功能边界、协商技术方案、定义验收标准。

## Workflow

1. **What (需求意图捕获)**: 理解用户想构建什么
2. **How (功能边界界定)**: 决策树细化实现路径
3. **Tech (技术方案协商)**: 推荐合适的技术栈组合
4. **QC (验收标准定义)**: 生成可验证的测试用例模板

## Rules

- 每次只问一个问题，等待用户回答
- 每个确认点立即调用 `update_requirements` 工具写入需求文档
- 用户拥有最终决策权
- 状态流转: draft → confirmed → done

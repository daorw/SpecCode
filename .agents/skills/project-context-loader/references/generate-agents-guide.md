# 生成 AGENTS.md 指南

当 `/AGENTS.md` 不存在时，执行以下步骤生成项目规范文档。

## 1. 分析项目结构

- 读取 `README.md` 了解项目概述
- 识别项目类型（前端/后端/全栈/库等）
- 识别技术栈（语言、框架、工具）
- 分析目录结构

## 2. 识别关键文件

- 配置文件：`package.json`、`pyproject.toml`、`Cargo.toml` 等
- 入口文件：`main.py`、`index.js`、`app.py` 等
- 架构文档：`ARCHITECTURE.md`、`docs/` 下的文档
- 测试目录：`tests/`、`__tests__/`、`spec/` 等

## 3. 生成 AGENTS.md

使用以下结构生成文档：

```markdown
# 项目开发规范

## 项目概述
- 项目名称、用途、目标用户
- 技术栈
- 项目结构概览

## 架构设计
- 整体架构图/描述
- 核心模块及职责
- 数据流向
- 关键设计模式

## 开发规范
- 代码风格（缩进、命名、注释）
- 文件组织原则
- 依赖管理规范
- 错误处理规范

## 测试规范
- 测试框架
- 测试文件位置
- 测试命名规范
- 覆盖率要求

## 开发流程
- 添加新功能的步骤
- 代码审查清单
- 文档更新要求
```

## 4. 用户确认

- 向用户展示生成的 AGENTS.md 内容
- 询问是否需要调整
- 根据反馈修改
- 用户确认后写入 `/AGENTS.md`
